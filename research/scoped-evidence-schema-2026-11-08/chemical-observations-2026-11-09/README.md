# Chemical observation consumers

This follow-up implements the chemical-observation gap discovered while checking the legacy payload comparison in data draft [#369](https://github.com/judegomila/OnCo/pull/369). A free drug, attached drug-linker, released catabolite and subsequent metabolite are not interchangeable. The endpoint, exact species, context, method, source, check date and evidence type now travel together.

The optional `Term.chemicalObservations` field uses structural alternatives. Transporter endpoints require named transporters; substrate and inhibition are distinct. Loading statements require a named conjugate or preparation and retain source wording about ranges/approximations without inventing a fixed mean. Numeric component loading remains the separate existing quantity contract. Missing observations produce an explicit not-recorded state, not false or zero.

The comparison reader uses these observations instead of the legacy permeability boolean and unscoped efflux grade. Glossary pages display the same scoped details. Exact-species queries retain all matching source findings and can restrict a loading observation to its named conjugate. Search, atomic passages and the mechanism-answer path retain the source context; differing observations are kept together. Actual entity JSON, JSON Schema and Markdown context exports were generated and checked. Explicit species and conjugate references have distinct graph relations.

[Scope](scope.json), [API verification](api-verification.json), [matched static renders](render-verification.json) and [validation](validation.json) record the tested paths. The temporary integration used the actual 65-owner data draft and retained all 46 observations through JSON, Markdown and the reader. All 19 temporary data-file overlays were restored by byte hash, then the standalone API was regenerated. Original HTML and generated JSON/Markdown bodies stay outside Git; receipts retain hashes.

The final standalone suite passes 286 files and 2,838 tests, with two existing skips. Validation accepts 22,683 records; typecheck passes and lint has zero errors with seven pre-existing warnings. The new chemical follow-up has matched static markup and actual export checks; it has no new production-build, browser-hydration, responsive-visual or hosted-preview claim. Historical build/browser results elsewhere in this proposal apply to their earlier checkpoints.

Data draft #369 and this product implementation are a coordinated release dependency. The data branch alone retains the baseline comparison reader and strips the new canonical field under its baseline schema. This product branch alone has no newly populated chemical observations. Neither combination is described as shipped. Owner review remains required. Broader ambiguous-prose inference/classification is still under audit; no global chemical-identity certification is claimed.
